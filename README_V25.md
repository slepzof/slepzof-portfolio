# SLEPZOF v25

Основа: v24. Первый экран сверстан по Main.pdf, полный текст без изменений.

- Общая синяя плашка и новый хедер с семью пунктами меню на всех публичных страницах.
- Hero с оригинальными заголовком, описанием, CTA и полноширинной Lottie-анимацией.
- Новый JSON Animated-iPhone-mockups-no-watermark(1).json вместо прошлого файла.
- SVG иконки Translate, Telegram, Email, Phone, Download, предоставленные пользователем.
- Общая закрепленная полупрозрачная панель из четырех контактов.
- Десктоп, планшет, мобильный адаптив.
- Каталог, кейсы и CMS v24 сохранены.

Запуск: `python3 server.py`, затем `http://localhost:8000`.

Lottie использует lottie-web с CDN и fallback-картинку, если CDN недоступен. Для локальной работы анимации без сети требуется разместить локальную библиотеку `lottie.min.js` в vendor и обновить её адрес в js/v20.js.

Дополнительно: прозрачная статичная заставка `assets/animations/hero-fallback.webp` получена из прикрепленного пользователем `Main.pdf` и заменяет старую заставку с Hash Hedge, пока Lottie загружается или при отсутствии сети.
