# SLEPZOF v13

Исправления только в карточках кейсов и их сетках, поверх проекта v12 (исходно v11).

- Убраны принудительное осветление и смешивание плейсхолдеров с цветами карточек.
- Новый принцип: цвет карточки, оригинальный мокап без фильтра, отдельная типографика и метрики.
- Добавлены иконки из прикрепленных пользователем SVG для дизайна, разработки, руководства, маркетинга, лауреаты метрик.
- Добавлены изображения, выделенные из переданных Figma SVG для Pixel Drop, воронки, Parking, Vita AI и ЭХО.
- Для проектов без настоящих изображений старая заглушка скрыта. Можно заменить assets/cases/<slug>/cover.webp реальным изображением после включения в список v13.js.
- Hash Hedge выводит чистые устройства на цветном фоне.
- Сетка выбранных и рабочих периодов, а также каталог адаптированы к единой системе.
- Исходные данные, кейсы, тексты, навигация не менялись.
