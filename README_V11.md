# SLEPZOF v11

Продолжение v10. Статический адаптивный сайт с единой системой страниц и карточек.

## Запуск

На Mac из папки сайта: `python3 -m http.server 8000`. Адрес: http://localhost:8000

## Что изменено

- Hero: новый заголовок, прямой статус Full-time / Remote, более компактный переход к метрикам.
- Метрики: вместо счетчиков экранов в главном блоке 200+ работ и задач, 24 обученных человека, 52 сотрудника под руководством, 160k+ лидов. Резюме вынесено в заметную синюю кнопку.
- Карточки: цветные поверхности под будущие фирменные цвета, изображение прилегает к краям, роли объединены одной нейтральной палитрой, подписи и метрики перестроены.
- Опыт: автоматическая мозаика 1–7 проектов, прокрутка страницами только для больших наборов. Нет стрелок и пустых ячеек при 1–2 проектах.
- BONAPE, SALUTE, ARTSAVUR, FORFIS и другие периоды ведут в соответствующую выборку единого каталога, а не в случайный одиночный кейс.
- Каталог: единая разноформатная витрина без заголовков работодателей, с поиском и фильтрацией по ролям. Страница `/projects/?period=artsavur` показывает работы определённого периода.
- Пекарня: самостоятельный текстовый блок на главной, фото можно заменить одним файлом.
- Сотрудничество: Remote, Full-time, гибрид и офис показаны как отдельные варианты.
- Hash Hedge: переработаны 3 решения и иерархия блока метрик. DuckMaster и Onlinesklad получили более понятные показатели масштаба.
- Единый header/footer на всех 150 страницах кейсов и сайте.

## Где менять визуалы

- Главный визуал: `assets/home/hero.webp`.
- Фото пекарни: `assets/about/bakery.webp`.
- Обложки: `assets/cases/slug/cover.webp`.
- Папки галерей и замена экранов: см. `GALLERY_GUIDE.md`.
- Акцентный оттенок каждой плитки: переменная `--sx-tile-color` в HTML (по умолчанию приглушенная палитра).
- Весь новый внешний вид содержится в `css/v11.css`, исходные CSS v10 не удалены.
- Группировка и фильтры каталога: `js/v11.js`.

Данные о работе и датах сохранены из v10, в дополнение к изменениям списка SALUTE. Числа для неподтвержденных по данным проекта результатов не сгенерированы. RU/ENG переключатель пока не внедрён.
