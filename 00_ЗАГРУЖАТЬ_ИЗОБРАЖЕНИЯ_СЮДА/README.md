# SLEPZOF — ЕДИНАЯ ПАПКА ДЛЯ ЗАГРУЗКИ ИЗОБРАЖЕНИЙ

**Кидай сюда ЛЮБЫЕ изображения скопом. Не раскладывай и не переименовывай.**

Сюда подходят:
- Обложки кейсов, экраны приложений, скриншоты сайтов
- Изображения новых блоков главной страницы (например, «Процесс работы»)
- Фото, иллюстрации, иконки, логотипы, SVG
- Изображения для внутренних страниц и будущих статей

Загружай PNG, JPG, JPEG, WebP, SVG через GitHub Desktop в ветку `dev`.
Исходное качество сохраняй. Большие файлы можно добавлять несколькими коммитами.

**После Push** напиши в ChatGPT:
«Загрузил изображения в 00_ЗАГРУЖАТЬ_ИЗОБРАЖЕНИЯ_СЮДА: [для какого блока/кейса и какие файлы]».

Далее ChatGPT:
1. Проверяет, какие файлы появились во входящей папке.
2. Сверяет назначения с согласованным дизайном и указанным блоком.
3. Сопоставляет материалы с проектами, переименовывает понятными именами.
4. Раскладывает по `assets/cases/<slug>/`, `assets/articles/<slug>/` или
   соответствующим каталогам блоков главной страницы.
5. Подключает картинки к странице и проверяет сборку/отображение.
6. **Только после проверки размещения** удаляет разобранные копии из входящей
   папки, чтобы она была готова к следующей партии.

Неоднозначные файлы остаются на месте, пока не станет понятно, куда их
поместить. Не допускается угадывание или перезапись утверждённого медиа.

**Эта папка не входит в GitHub Pages сборку** и не отображается на сайте.
Однако репозиторий публичный: не загружай сюда секретные материалы или
файлы, которые нельзя распространять.

Дополнительные правила для изображений: `docs/MEDIA-UPLOAD-GUIDE.md`.
