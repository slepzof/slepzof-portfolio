# Блок 3 · Слайдер без правки контента

База: SLEPZOF_Portfolio_v25_Block03_Fixed.zip.
Сохранены все 9 карточек, их изображения, названия, описания, оригинальные строки метрик, два венка вокруг каждой цифры, стрелки и ссылки на страницы кейсов.
Изменены только структура секции `#selected` (grid/раскрытие -> горизонтальная лента), локальные CSS/JS секции и навигация стрелками. Блоки 1 и 2 не затронуты.

- ПК: три карточки плюс видимая часть следующей.
- Мобильный: около 1.4-1.5 карточки, горизонтальная обрезка окна; карточки не растягиваются на всю ширину.
- Свайп, трекпад, стрелки, клавиатура, scroll-snap, hover zoom.
- Контент/венки не удаляются и не переписываются. Длинные подписи могут занимать несколько строк в доступной плашке, без обрезки текста.
- Скроллбар самой ленты скрыт; горизонтальный скролл сайта не возникает.

Запуск из корня `python3 server.py`, адрес `http://localhost:8000/`.
