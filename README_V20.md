# SLEPZOF v20

В HERO вместо статичной картинки Hash Hedge подключена исходная Lottie-анимация `assets/animations/hero-iphone.json` (7200 × 2048, 60 FPS).

Установка: разархивировать целиком, запустить локальный HTTP-сервер в корне сайта (`python3 -m http.server 8000`) и открыть http://localhost:8000/.

Важно: код проигрывателя Lottie загружается с `cdnjs.cloudflare.com` (lottie-web 5.12.2). Для анимации нужен интернет при первом открытии сайта. JSON анимации и все встроенные изображения хранятся локально, внутри архива. Если загрузка библиотеки заблокирована, анимация не запустится.

Для пользователей с включённым `Reduce Motion` анимация показывается без движения. Все остальные страницы v19 оставлены без изменений.
