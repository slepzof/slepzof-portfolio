# SLEPZOF v10

Статический сайт HTML/CSS/JS. Основа: v9, отдельный редизайн главной, каталога и страниц о себе.

## Замена изображений
- Главный визуал: `assets/home/hero.webp`
- Обложки: `assets/cases/<slug>/cover.webp`
- История: `assets/about/story-01.webp`, `story-02.webp` ... `story-11.webp`
- Существующие галереи: соответствующие папки `assets/cases/<slug>/gallery/`
- Для новых карточек кейсов: рядом с `cover.webp` создайте `gallery/` и добавьте картинки. Для статического хостинга запустите имеющийся скрипт `refresh_galleries.py`, если галереи требуют манифеста.

## Данные
`data/projects.json` содержит стадии, точные периоды, заголовки, проекты, результаты и направления. Генератор: `/mnt/data/build_slepzof_v10.py` (передавайте вместе с исходниками для полной пересборки).

## Запуск
Откройте терминал в папке сайта: `python3 -m http.server 8000`, затем http://localhost:8000.

## Публикация
Загрузите содержимое папки на Cloudflare Pages через Direct Upload.
