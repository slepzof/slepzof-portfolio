# Beyond UI (v25)

Новый блок находится после «Избранных проектов» на главной странице.

- `css/v28-beyond-ui.css`: оформление, radar sticky, мобильная fade-подложка, проектные карточки.
- `js/v28-beyond-ui.js`: активный навык от вертикального скролла, клики по радару, горизонтальная навигация по проектам.
- `index.html`: вступление и восемь статических состояний навыков.
- Во всех восьми навыках временно стоят **три одинаковые Onlinesklad**; заменить позже по согласованным проектам.
- Нет принудительного захвата wheel/touch; это нативный скролл с закреплённым радаром.
- SVG-дизайн радара реализован как векторные элементы с DOM-управлением, без огромных SVG-экспортов целого экрана.
- Проверялся изолированный UI в headless Chromium (1440/390/320); полноценное поведение всего сайта в Safari на устройстве разработчика требует визуальной проверки.

Запуск: `python3 server.py` и затем http://localhost:8000/
