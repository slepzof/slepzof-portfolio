# Блок 02 · Метрики опыта (Figma 1440 × 162)

В основе остаётся обновлённая v25 с первым блоком и исходной Lottie-анимацией телефонов.

Файлы: `index.html`, `css/v25-block2.css`, `js/v25-block2.js`.

- Цифры: 6, 5, 121, 24, 52, 160k+; подписи соответствуют предоставленному макету.
- Плавный отсчёт от 0 до конечного числа длительностью 1,6 сек, при первом появлении блока в области просмотра. Повторного запуска при прокрутке нет.
- В последней метрике меняется только `160`, суффикс `k+` статичный.
- При выключенном JavaScript и при `prefers-reduced-motion` видны готовые значения без анимации.
- Desktop: 6 колонок; планшет: 3; мобильный: 2. Десктоп сверян с экспортом 1440 × 162.
- Опечатка в исходном макете "привелечённых" исправлена на "привлечённых".

Другие блоки, CMS, карточки проектов, изображения и анимация телефонов не менялись.
