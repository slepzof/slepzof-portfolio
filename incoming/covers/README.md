# SLEPZOF — входящие обложки кейсов

**Сюда можно загружать все новые обложки одним списком через GitHub Desktop.**
Файлы не нужно заранее переименовывать или раскладывать по проектам.
Допустимы PNG, JPG, JPEG, WebP и SVG. Никакого ручного сжатия.

- Папка: `incoming/covers/`
- Рабочая ветка: `dev`
- Можно загружать 120 и более исходников, но **отдельный файл должен быть меньше 100 МБ** (ограничение GitHub).
- Лучше сохранить исходные названия, чтобы можно было восстановить соответствие проектам.
- Не удаляйте исходники после загрузки. Сначала нужна проверка сопоставления.

После загрузки напишите в чате «Загрузил обложки в incoming/covers, разбери».
Далее ассистент проверяет содержимое GitHub, сопоставляет файлы с кейсами,
переименовывает в понятные slug и переносит в `assets/cases/<slug>/cover.*`.
Если название не позволяет надёжно установить проект, файл остаётся во входящей
папке до уточнения. Никаких угадываний и перезаписи утверждённых обложек.

**Важно:** папка `incoming/` не включена в список публикуемых каталогов
`scripts/build_static.py`, поэтому сырые изображения из неё не появляются
на GitHub Pages автоматически. Но сам репозиторий публичный — не загружайте
туда личные или конфиденциальные фотографии.

Обложки, утверждённые для публикации, затем проходят через медиапайплайн
`scripts/optimize_media.py`, когда подключены к HTML-компонентам.
