# Карта изображений для самостоятельной замены

Изображения организованы по смыслу блока. Стабильное имя файла — контракт: можно заменить файл с тем же именем и расширением без редактирования HTML.

## Главная → «Каждый рынок»

Папка: `assets/home/markets/`.

`igaming.png`, `fintech.png`, `automotive.png`, `e-commerce.svg`, `sports.png`, `edtech.png`, `travel.png`, `foodtech.svg`, `saas.png`, `martech.svg`, `proptech.png`, `healthtech.png`, `industrial.svg`, `social.png`, `hrtech.png`, `legaltech.png`.

12 растровых артов используются на ПК и в мобильной колоде; 4 SVG из этого набора сохранены как исходные ассеты метрик и иконок. Сами метрики в разметке выполнены текстом/иконками, поэтому замена этих четырёх SVG **не** изменит их автоматически.

Карточки десктопного референса: 262 × 256 CSS px. Для растрового арта целевое разрешение хотя бы 524 × 512 px, если он растягивается на всю карточку.

## Кейсы

`assets/cases/<slug>/` — отдельная папка материалов каждого кейса. На существующих страницах могут использоваться `cover.webp`, `hero.webp`, `overview.webp` и папка `gallery/`. Список файлов нужно сверять с конкретной страницей `cases/<slug>/index.html`.

## Практическая замена

1. В GitHub Desktop открыть `Repository → Show in Finder`.
2. Найти папку по карте выше и заменить файл, **не меняя имя**.
3. Commit → Push в `dev`; после успешного deploy проверить ПК и мобильную версию.
4. Если формат или название меняется, понадобится обновить пути в HTML, CSS или данных CMS.
5. Не заменять фотографии / объекты, не меняя согласованный макет.

Для новых блоков выбирать названия `assets/home/<block>/<semantic-name>.<ext>` (не `final-v3-new`).
