# Аудит репозитория: 11 ноября 2026

Перед очисткой в `dev` было 849 файлов, в том числе 40+ CSS и 30+ JS, большая часть из разных итераций портфолио. Главная `index.html` около 530 КБ.

## Сделано

- Добавлен живой Style Guide и четыре базовых общих CSS-файла.
- Подготовлены Light/Dark tokens, строгая типографика, сетка, компоненты.
- 9 изображений `process-v38/` перемещены в `assets/home/process/`.
- 16 изображений `assets/markets/` перемещены в `assets/home/markets/`.
- 36 файлов документации/QA перемещены из корня в `docs/archive/`. Исторические копии доступны для справки.
- Удалена временная логика копирования `process-v38/` в статическом build script.

## Не удалять без дополнительной проверки

- `css/v*.css` и `js/v*.js`: разные страницы (включая кейсы) ещё используют ранние версии.
- `assets/cases/`: контент проектов.
- `cms/`, `data/`: действующие исходники и контент.

## Оставшаяся техническая задолженность

- Главная страница остаётся большим HTML, а не сборкой из модулей.
- Многие старые селекторы ещё задают размеры/цвета вручную; миграция на токены ведётся поэтапно.
- Публичную замену текста/изображений из админки нужно реализовать отдельно и безопасно, не хранить GitHub-токены в JS.
- Визуальная сверка с Safari по разрешениям пока требует отдельного теста пользователя/браузера.
