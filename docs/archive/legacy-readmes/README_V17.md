# SLEPZOF v17: Избранные проекты

Вместо ошибочной сетки v16 сделано 3 страницы по 2 крупные карточки: Hash Hedge / Onlinesklad, DuckMaster / Sober Driver, Apple Bar / Pixel Drop. Использованы исходные 6 фонов 1184×980, без запечённых текстов. Заголовки, описания, роли и метрики сделаны HTML и масштабируются адаптивно. Иконки ролей и венки взяты из приложенных SVG. Навигация стрелками, точками, свайпом и клавиатурой. Другие блоки и страницы сохранены из v16.
