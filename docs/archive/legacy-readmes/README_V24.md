# SLEPZOF v24: обновлённый первый экран

- Переработаны заголовок, описание, CTA и общий хедер на всех публичных страницах.
- Статус доступности встроен в общую синюю полосу до навигации.
- Lottie показывается целиком в пропорции исходного файла (7200 x 2048), без мобильного масштаба 180%, без фиксированной высоты и перекрывающей накладки справа.
- Отдельные размеры типографики и навигация для десктопа, планшета и мобильных устройств.
- Сохранены все страницы, 123 проекта и админка v23.

Локальный запуск: `python3 server.py`, затем `http://localhost:8000/` или `/admin/`.

Если анимация не запускается из-за недоступности CDN `lottie-web`, остаётся статичная иллюстрация; исходный Lottie JSON не изменён. В оригинальном файле длительность около 36,5 сек. Если требуется полностью автономное воспроизведение без интернета, добавьте локальный `lottie.min.js` и обновите первый адрес в `js/v20.js`.
