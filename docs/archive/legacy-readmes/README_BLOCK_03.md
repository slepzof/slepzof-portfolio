# SLEPZOF v25 – Block 03 «Избранные проекты»

- База: SLEPZOF_Portfolio_v25_Block02.zip, оба предыдущих блока сохранены.
- В #selected заменена прежняя карусель на сетку 3×2 и раскрываемый третий ряд (всего 9 проектов).
- Изображения: девять точных оригинальных PNG-обложек, предоставленных пользователем, лежат в assets/featured-v25-block3/.
- Текст и метрики — по предоставленным макетам. Подпись к метрикам вынесена в HTML поверх изображений.
- Подключены css/v25-block3.css и js/v25-block3.js только для главной страницы.
- Клик по карточке ведёт на существующий URL кейса. Клик «Показать ещё 3 проекта» раскрывает дополнительный ряд и меняется на «Скрыть проекты».
- Исходный сайт и локальная CMS не удалены. Этот блок имеет собственную HTML-разметку, чтобы исходные данные CMS v25 не затирали новые макетные тексты и иллюстрации. Если потребуется редактирование именно этих 9 карточек через админку, нужно отдельно адаптировать редактор CMS под новую структуру.
- Mobile адаптив выполнен по десктопному макету (пользователь отдельно его не проектирует).

Запуск: `python3 server.py`, адрес: http://localhost:8000/ .
