# Block 03 v4 — визуальные правки

База: SLEPZOF_Portfolio_v25_Block03_Correct_Slider.zip.

- Все 9 карт: стрелки вместо плюсов.
- Обводка/outline/shadow у нижних плашек и круглых стрелок убраны; сами венки и оригинальные показатели оставлены.
- Утвержденные названия и метрики не переписаны. Переносы заголовков и подписей зафиксированы HTML `<br>`.
- Для ПК: ширина карты 326 px вместо 355 px, высота пропорциональная 469 px, уменьшены вертикальные отступы заголовка, сетки и стрелок. При 1440 px помещается весь блок целиком в пределах 900px тестового viewport.
- Для мобильного: те же горизонтальные карточки со срезом ленты, без растяжения/stack grid.
- Полный Safari рендер должен быть проверен пользователем локально; проверялся изолированный рендер Chromium с реальными CSS и изображениями.
- Слайдер, scroll snap, свайп, hover zoom и девять переходов на кейсы сохранены.
- Изоляция изменений: только секция `#selected`, новый CSS и JS-файл для неё.

Запуск: `python3 server.py` из корня проекта.
