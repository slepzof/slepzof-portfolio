# SLEPZOF Design System v1.0

**Источник истины:** утверждённые макеты SLEPZOF. Сетка 1440 → 1116 px (по 162px справа и слева), системный шрифт Apple, единая типографическая шкала. Любое визуальное исключение должно иметь конкретный референс.

[Живой Style Guide](https://slepzof.github.io/slepzof-portfolio/design/style-guide/)

## Файлы

- `css/system/tokens.css` — единые значения.
- `css/system/typography.css` — текстовые классы.
- `css/system/layout.css` — контейнеры, колонки, интервалы.
- `css/system/components.css` — общие кнопки, поля, карточки, badges.

**Использовать классы, а не подменять смысл HTML:** H2 для семантики, `.ds-h2` для внешнего вида. Не задавать глобально `h3{font-size:40px}`, иначе пострадают старые карточки, в которых H3 — не крупный заголовок секции.

## Сетка

- ≥1280 px: 12 колонок с gap 24px, центральный контейнер 1116px. Боковые поля на 1440 = 162px.
- 1024–1279 px: 12 колонок, поля 40px.
- 768–1023 px: 8 колонок, поля 32px.
- 481–767 px: 4 колонки, поля 24px.
- 361–480 px: 4 колонки, поля 20px.
- 320–360 px: 4 колонки, поля 16px.

`ds-container`: обычные блоки, `ds-container-narrow`: статьи и текст, `ds-container-wide`: крупные композиции, `ds-breakout-right`: горизонтальные галереи. Выход за сетку должен быть предусмотрен дизайном и не менять общие 1116px.

## Вертикальные отступы

Базовая шкала: 4, 8, 12, 16, 24, 32, 48, 64, 80, 96 px. Секции: 96px desktop / 80px tablet / 64px mobile. Заголовок → контент: 64 / 48 / 32px. Внутри крупной панели: 64 / 40 / 24px. Gap карточек: 24 / 20 / 16px.

**Важное правило:** JS не должен оставлять пустой runway после завершения sticky-секции. Sticky-элемент должен иметь высоту окна браузера, а высокая композиция движется внутри него.

## Темы

`data-theme="light"` / `data-theme="dark"` задают семантические цвета через `--ds-color-*`. Можно использовать `.ds-theme-dark` только для отдельной секции. **Утверждённые чёрные или белые блоки не инвертировать автоматически**, пока не согласован отдельный дизайн тёмного режима всей страницы.

Светлая палитра: bg #FFFFFF, surface #F5F5F7, ink #1D1D1F, muted #6E6E73, blue #007AFF. Тёмная: bg #000000, surface #141414, ink #F5F5F7, muted #98989D, blue #0A84FF. Остальные токены, включая системные цвета графиков, находятся в `tokens.css`.

## Компоненты

```html
<h2 class="ds-h2">Название секции</h2>
<p class="ds-lead-xl ds-text-secondary">Описание.</p>
<a class="ds-button ds-button--primary" href="/projects/">Смотреть проекты</a>
<a class="ds-button ds-button--secondary" href="/work-with-me/">Работа со мной</a>
<a class="ds-button ds-button--tertiary" href="/about/">Обо мне →</a>
```

Кнопки имеют единые состояния hover, active, focus, disabled, а также размеры sm и lg. Пользовательские фото и макеты не изменяются при подключении дизайн-системы.

## Договор о будущих изменениях

Перед версткой сверять макет → выбирать токены → собирать из компонентов → добавлять только уникальную композицию → визуально проверять на 1920, 1440, 1024, 768, 480, 428, 393, 360 и 320 px → проверять прямую и обратную прокрутку.
