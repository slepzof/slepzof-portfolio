# SLEPZOF Portfolio

Исходники портфолио SLEPZOF. Текущая рабочая версия: **v35**.

## Как устроена работа

- `main` — стабильная версия.
- `dev` — текущие изменения и предпросмотр на MacBook и iPhone.
- Изменения в GitHub автоматически публикуются через **Cloudflare Pages** после подключения репозитория.

> Сейчас репозиторий подготовлен под загрузку сайта. Файлы самой v35 нужно поместить в корень репозитория из подготовленного архива — до этого сайт не опубликован.

## Сборка статического предпросмотра

```bash
python3 scripts/build_static.py
```

Папка `dist/` — готовая статическая версия для Cloudflare Pages. Локальная Python-админка не публикуется. Если необходимо редактировать контент через CMS, на MacBook продолжает работать `python3 server.py`.

См. [DEPLOY.md](DEPLOY.md).

### Правила разработки

- Утверждённый дизайн, текст, метрики и изображения не изменять без согласования.
- Каждую правку оформлять отдельным коммитом в `dev`.
- Проверять десктопную и мобильную версии по ссылке предпросмотра.
- Только утверждённые изменения переносить из `dev` в `main`.
- Не коммитить секреты, пароли и .env-файлы.

**Внимание:** репозиторий сейчас публичный; всё, что в него загрузить, может быть доступно другим.
