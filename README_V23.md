# SLEPZOF Portfolio v23: локальный редактор контента

Версия 23 сделана поверх оригинального сайта v22. Старые страницы и оформление сохранены. Новая админка работает локально, без аккаунта, сторонних сервисов или базы данных.

## Быстрый запуск на Mac

1. Распакуйте `SLEPZOF_Portfolio_v23.zip` в любую папку.
2. Откройте Terminal в папке `slepzof-portfolio-v23`.
3. Выполните `python3 server.py`.
4. В браузере откройте `http://localhost:8000/admin/`.
5. Для просмотра публичного сайта используйте `http://localhost:8000/`.

**Важно:** для сохранения используйте `python3 server.py`, а НЕ `python3 -m http.server`. Обычный HTTP-сервер не умеет принимать загрузки и сохранять изменения в файлы.

## Что есть в админке

### Проекты
- Список 123 существующих проектов с поиском, выбором, дублированием и добавлением новых.
- 4 независимых макета карточек: большая 2×2, средняя вертикальная 1×2, средняя горизонтальная 2×1, маленькая 1×1.
- Название, описание, роль, период, фирменный цвет, цвет текста, числовая метрика, адрес страницы.
- 3 отдельные фоновые картинки: ПК (от 1025px), планшет (641–1024px), телефон (до 640px). Если вариант отсутствует, используется имеющийся.
- Шаблон для новых страниц кейса: о проекте, задача, решение, результат, галерея изображений. Страница создаётся автоматически при сохранении.
- Добавленные кейсы появляются в общем каталоге и соответствующем разделе главной страницы. Переполненные разделы автоматически пакуются по страницам с двумя рядами на ПК.
- Существующие кейсы первоначально не изменены. Чтобы опубликовать редактирование карточки, используется переключатель «Опубликовать изменения карточки».

### Тексты и изображения
- Выбор любой страницы, включая все прежние страницы кейсов.
- Открытие предпросмотра в панели админки.
- Кликните по надписи, фотографии или доступной фоновой области, внесите изменение и нажмите «Применить».
- По необходимости можно заменить точно совпадающую короткую фразу на всех страницах, например в меню и футере.
- Затем сохраните правки кнопкой в верхней панели.
- Ссылку выбранного текстового элемента можно заменить в поле «Адрес ссылки».

### Экспорт и перенос
- «Скачать полный архив» включает админку, все исходники, изменения и изображения.
- «Экспорт публичного сайта» исключает админку и файл серверного приложения. Полученный сайт открывается как обычный статический сайт через HTTP.
- «Скачать JSON» делает отдельную резервную копию текстов и настроек. Изображения в неё не входят, поэтому для полноценного бэкапа выбирайте полный архив.

## Где хранятся изменения

- `cms/data.json`: проекты и все редактируемые тексты.
- `assets/cms-uploads/`: новые PNG, JPG, WebP, GIF и AVIF изображения.
- `cases/<slug>/index.html`: страницы новых проектов, созданные шаблоном.
- `admin/`: временная панель редактора.
- `server.py`: локальный сервер, сохранение, загрузки и экспорт.
- `js/site-cms.js`, `css/cms-runtime.css`: подключение изменённого контента к публичным страницам.

Чтобы **убрать админку с публичного сайта**, используйте кнопку «Экспорт публичного сайта». Публичный сайт будет читать сохранённый контент из `cms/data.json`. Не размещайте локальный сервер с админкой в общем доступе без отдельной авторизации. Сейчас сервер намеренно принимает соединения только с `127.0.0.1`.

## Особенности шаблонов

Существующие подробно свёрстанные страницы не переписываются целиком на общий шаблон, поэтому оригинальные дизайны и кейсы остаются неизменными. Их текст и изображения редактируются визуально. Новые кейсы создаются из простого единого шаблона, который можно расширить, когда будут готовы содержание и макеты. После структурной ручной переделки HTML некоторые точечные правки, выбранные визуальным редактором, может потребоваться выбрать повторно.

## Технические требования

- Python 3.9+ без дополнительных пакетов.
- Современный Safari, Chrome или Firefox.
- Все файлы, включая загрузки, находятся в папке проекта. Для доступа с других компьютеров переносите всю папку или скачивайте полный архив.
