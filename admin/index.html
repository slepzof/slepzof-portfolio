Файл JSON со всеми правками. Удобен для восстановления текстов и структуры. Для изображений нужен полный архив.

Как пользоваться после переноса

Запускайте python3 server.py, затем открывайте http://localhost:8000/admin/. На хостинге админку не публикуйте без отдельной аутентификации. Публичный сайт работает как обычный статический HTML.
